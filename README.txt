OCRE COMPANION — PWA

Ce dossier contient une Progressive Web App prête à être hébergée.

Fichiers principaux :
- index.html : application
- manifest.webmanifest : installation sur l’écran d’accueil
- service-worker.js : fonctionnement hors ligne
- icons/ : icônes iPhone/PWA

Une fois hébergée en HTTPS :
1. Ouvrir l’adresse dans Safari sur iPhone.
2. Toucher Partager.
3. Choisir Ajouter à l’écran d’accueil.
4. Activer Ouvrir comme app web si l’option apparaît.
5. Valider.

La progression reste stockée localement sur l’iPhone. Utiliser régulièrement le bouton Sauvegarde.
